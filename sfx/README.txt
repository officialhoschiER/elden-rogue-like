ELDEN ROGUE - MENÜ-SOUNDS
=========================

Lege hier zwei Audiodateien ab, dann spielt das Hauptmenü sie automatisch:

  sfx/hover.mp3   -> kurzer Sound beim Drüberfahren über Buttons (Hover)
  sfx/select.mp3  -> Sound beim Klick / Auswahl

Wichtig:
- Format MP3 (breit unterstützt). Kurz halten (Hover < 0,3 s, Select < 0,5 s).
- Lautstärke lässt sich im Spiel unter Einstellungen -> Lautstärke regeln.
- Fehlen die Dateien, bleibt das Menü einfach still (kein Fehler).

Woher lizenzfrei (CC0 / royalty-free) nehmen?
- pixabay.com/sound-effects  (Suche z.B. "menu hover metal", "UI select sword", "sword unsheathe")
- freesound.org  (auf CC0-Lizenz achten)
- mixkit.co/free-sound-effects/interface

Tipp für Elden-Ring-Feeling:
- Hover: ein schneller, heller Metall-/"Shing"-Wisch (Klinge).
- Select: ein satter, tiefer metallischer "Dink"/Klick.

Das Original aus Elden Ring darf aus Copyright-Gründen NICHT verwendet werden –
nimm ähnlich klingende, frei lizenzierte Sounds.
